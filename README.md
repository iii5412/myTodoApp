# 할 일 (myTodoApp)

안드로이드에서 쓰는 개인용 할 일 앱.

- **잠금을 풀면 바로 실행**되어 오늘 할 일이 한눈에 보인다.
- 새 할 일은 목록 위에 추가된다. 일정이 없는 할 일은 **길게 눌러 드래그**해서 순서를 바꿀 수 있다.
- **날짜·시간은 선택 사항**이다. 일정이 있으면 현재 시각과 가까운 순서로 먼저 표시된다.
- `내일 오후 3시 병원`, `10월 20일 오전 9시 회의`, `금요일 18:00 운동`, `30분 후 전화`처럼 입력하면 기기 안에서 일정을 자동 설정한다. 날짜만 있으면 오전 9시, 시간만 있으면 다음 해당 시각을 사용한다. 등록 전에 날짜·시간 옵션에서 수정하거나 지울 수 있고, 직접 선택한 값이 우선한다. 입력한 문구는 그대로 유지된다.
- 오전·오후 없이 적은 `1시`~`6시`와 `3:30` 같은 시각은 오후로 해석한다. `새벽 3시`, `아침 6시`, `오전 4시`는 오전이며, `03:30` 같은 두 자리 24시간 표기는 그대로 쓴다.
- 수정 화면에서 날짜·시간 표현을 바꾸면 일정도 함께 바뀐다. 설명만 바꾸면 기존 일정을 유지하고, 날짜·시간 표현을 지우면 일정도 해제한다. 수정 중 날짜·시간 옵션을 직접 바꾼 경우에는 그 값이 우선한다.
- 색 라벨, 남은 개수, 오늘 완료 진행 막대로 상태가 바로 보인다.
- 완료하면 **설정 > 완료 이력**에 날짜별로 쌓이고, 다시 할 일로 되돌릴 수 있다.
- 할 일 밀어서 삭제, 수정 화면 삭제, 완료 이력 개별·전체 삭제 모두 **확인창에서 삭제를 눌러야** 반영된다. 취소하거나 뒤로 가면 유지된다.
- 데이터는 **폰 안에만** 저장된다(서버로 보내지 않는다).

## 개발

```bash
npm install
npm run dev     # http://localhost:3000
npm test
```
